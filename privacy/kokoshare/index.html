最終更新: 2026年10月21日（共通プライバシーポリシーから独立したページに移しました。内容は2026年10月18日版と同じです） 事業者: Aju Works（個人事業）

このアプリの情報の取り扱い

ここシェアは、家族・友人への安否や現在地の連絡、登録地域の気象警報の確認、 防災メモ・備蓄の管理をまとめたアプリです。ログイン・アカウント登録・クラウド同期はありません。

端末内に保存する情報

  • 家族・連絡先（名前、続柄、電話番号、メモ）
  • 防災メモ（避難場所、連絡と集合のルール、服薬・アレルギー等）、備蓄
  • 端末内の安否記録、送る文、登録地域（最大3地域）、取得済みの気象情報

これらはAju Worksのサーバーへ送信しません。

位置情報

位置情報は初期状態でOFFです。利用者が「現在地を付ける」「いまここ」「待ち合わせ」「現在地」 「現在地の地域を追加」を押したときだけ、画面を開いている状態で1回取得します。 常時取得、バックグラウンドでの取得、移動履歴の保存は行いません。取得した座標は次の目的にだけ使います。

  • 送る文への添付：利用者が選んだLINE・メール等のアプリへ渡ります。
  • 地図プレビュー：OpenStreetMapへ座標が送られます。「Googleマップで開く」を選ぶとGoogleへ渡ります。
  • 現在地の警報確認・地域の追加：国土地理院の住所検索（逆ジオコーダー）へ座標を送り、市区町村を判定します。

座標はアプリに保存せず、Aju Worksのサーバーへも送信しません。

気象情報の取得

警報・注意報は、端末から気象庁の公開データ（XML）を直接取得して判定します。 この通信で気象庁にIPアドレス等の通信情報が伝わります。

警報の通知（任意）

利用者が「警報を通知する」をONにした場合のみ、Firebase Cloud Messaging（Google）を使用します。 通知のために、端末の登録トークン・Firebase Installation ID と、登録地域の購読情報（市区町村コード）がGoogleで扱われます。 氏名・電話番号・位置座標・健康情報・家族情報は通知の仕組みへ送信しません。 配信処理は気象庁の公開情報だけを扱い、利用者ごとのデータを保持しません。 通知をOFFにすると、購読の解除と登録トークンの削除を要求します。

広告・同意管理

Google Mobile Ads SDK（GMA 25.5.0）とGoogle User Messaging Platform（UMP 4.0.0）を使用して、ホーム画面のバナー広告と通常操作の区切りで全画面広告を表示し、同意・プライバシー設定を管理します。 SDKは広告配信、分析、不正防止のため、IPアドレス（一般的な位置の推定に使用される場合があります）、アプリ起動・タップ・広告視聴等の操作情報、アプリとSDKの診断情報、広告ID・App Set ID等の端末識別子を自動収集し、Google等の広告サービスと共有する場合があります。通信はTLSで暗号化されます。 家族・連絡先・安否・防災メモ・備蓄情報およびアプリ機能で取得した正確な位置情報は広告SDKへ渡さず、広告ターゲティングに使用しません。広告の同意・プライバシー選択は設定画面から確認・変更できます。

権限

  • 位置情報（おおよそ／正確） — ボタンを押したときの1回の取得
  • 通知 — 警報の通知（ONにした場合）
  • インターネット — 気象情報の取得、地図表示、通知

データの削除

アプリの「設定 → データを初期化」で端末内のデータを削除できます。アンインストールでも削除されます。 LINE・メール等へ送信済みの内容は、各サービス側で削除してください。

共通ポリシーとの関係

広告・課金・外部プラットフォーム・子どものプライバシーなどの共通事項は 共通プライバシーポリシー に記載しています。 本ページと共通ポリシーは併せて適用され、内容が異なる場合は本ページを優先します。 すべてのアプリの一覧は アプリ別プライバシーポリシー をご覧ください。
