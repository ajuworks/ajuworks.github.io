プライバシーポリシー

日々カウント - 記念日カウントダウン（com.ajuworks.countdown）／ Aju Works

最終更新: 2026年10月10日 事業者: Aju Works（個人事業）

1はじめに

本プライバシーポリシー（以下「本ポリシー」）は、Aju Works（以下「当事業者」）が提供する Androidアプリ「日々カウント - 記念日カウントダウン」 （Google Play 上の表示名。アプリ内の表示名は「日々カウント」。パッケージ名: com.ajuworks.countdown、 以下「日々カウント」または「本アプリ」）における情報の取り扱いについて定めるものです。

本アプリは、記念日や予定の日までの日数・時間をカウントダウン（過ぎた日からはカウントアップ）で表示するアプリです。 本ポリシーに定めのない事項については、 Aju Works 共通プライバシーポリシー が適用されます。

2アカウント登録について

本アプリの利用にあたって、アカウント登録やログインは必要ありません。 当事業者は、本アプリを通じて以下の情報を取得しません。

  • 氏名
  • メールアドレス
  • 電話番号
  • 位置情報

ただし、ユーザーご自身がお問い合わせのために送信された情報は、 お問い合わせへの回答のために利用します。

3イベント情報の取り扱い

本アプリでユーザーが登録・入力する以下の情報は、端末内のみに保存・処理されます。

  • イベントの名称
  • イベントの日付・時刻・タイムゾーン
  • メモ
  • 毎年繰り返し、お気に入り、通知のタイミング等のイベント設定
  • テーマ、表示形式（日数・日と時間・秒）、並び順等のアプリ設定
  • ホーム画面ウィジェットごとの表示設定

これらの情報を、当事業者が運営するサーバーやクラウドデータベースへ送信・保存・同期することはありません。 当事業者はサーバーを運用していません。また、本アプリは Android の自動バックアップを無効にしているため、 これらの情報が Google ドライブ等へバックアップされることもありません。

4背景写真の取り扱い

イベントの背景に写真を使う場合、Android の写真選択ツール（Photo Picker）でユーザーが選んだ写真だけを、 縮小したうえで本アプリ専用の保存領域へコピーします。 端末内の写真の一覧を読み取る権限（写真・動画へのアクセス権限）は要求しません。

コピーした写真は、アプリ内のカードとホーム画面ウィジェットの表示にのみ使用し、 外部へ送信することはありません。元の写真を変更・削除することもありません。

5通知について

「30日前」「前日」「当日」「1時間前」などのお知らせは、すべて端末内で生成されるローカル通知です。 当事業者が運営するプッシュ通知サーバーは存在せず、通知のためにイベント情報が外部へ送信されることはありません。

通知の受け取りは、端末の設定またはアプリ内のイベント設定から無効にできます。

イベントごとに任意でオンにできる「イベント時刻のアラーム」も、端末内で作られるローカル通知です。 Android の設定で全画面通知が許可されている場合に限り、ロック画面の上にも大きく表示します。 指定の時刻に鳴らすため、Android の「アラームとリマインダー」の許可を利用する場合があります（許可がない場合は数分遅れることがあります）。

6カレンダー連携

「カレンダーから追加」「カレンダーに追加」を使う場合に限り、端末のカレンダーの読み取り・書き込みの許可を求めます。 許可しなくても、カウントダウン・ウィジェット・通知などの機能はそのまま使えます。

  • カレンダーから追加: ユーザーが選んだ端末内のカレンダーの予定（タイトル・日時・繰り返し・メモ）を読み取り、確認のうえイベントとして登録します。
  • カレンダーに追加: ユーザーが選んだイベント（名称・日時・繰り返し・メモ）を、ユーザーが選んだ端末内のカレンダーへ予定として追加します。
  • 重複を防ぐため、取り込んだ／追加した予定の ID だけをイベントと一緒に端末内に保存します。

カレンダーの情報は端末内で処理され、当事業者のサーバーや第三者へ送信しません。 Google Calendar API などのオンラインのサービスは使用せず、Android 端末のカレンダー（Calendar Provider）を利用します。 Google カレンダーの予定は、端末に同期されている場合にのみ、この仕組みを通じて利用されます。 端末のカレンダーと Google アカウントとの同期は、Android および Google のサービスによって行われます。

7広告配信について（Google AdMob）

バージョン1.2.0以降の本アプリは、広告配信のために Google AdMob（Google Mobile Ads SDK）を利用しています。 ホーム画面下部のバナー広告と、新しいイベントを保存した直後に低い頻度で表示する全画面広告があります。 ウィジェット・通知・起動直後には広告を表示しません。 広告配信は当事業者ではなく Google LLC およびそのパートナーによって行われ、 広告SDKは当事業者のサーバーを経由せずに情報を送受信します。 インターネット通信は広告の取得・表示と同意確認のためにのみ行います。

広告SDKの動作にともない、Google およびそのパートナーが次のような情報を 取得・処理する場合があります。

  • 広告ID（Advertising ID）・App Set ID 等のデバイス識別子
  • IPアドレス等から推定される、おおよその位置情報（国・地域レベル）
  • 広告の表示回数・タップ等、アプリ内での広告に関する操作
  • 端末の機種・OSバージョン・言語設定・クラッシュ等の診断情報

これらの情報は、広告の配信・表示回数の計測・広告効果の分析・不正クリック等の 不正行為の防止・サービスの品質改善などの目的で処理されます。 本アプリの機能で扱うデータ（イベント・背景写真・カレンダーの予定）は、広告の仕組みには渡しません。 当事業者は、これらの情報を個人を特定する形で受け取ることはありません。

  • Google プライバシー ポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • AdMob とユーザーのプライバシー

EU・英国など、法令上同意の取得が必要な地域では、Google の User Messaging Platform（UMP）による 同意確認画面が表示され、アプリの設定画面「広告のプライバシー設定」から変更できます。 広告のパーソナライズは、Android端末の「設定 > プライバシー > 広告」から広告IDを削除・リセットすることで ユーザーご自身で制限できます。

8データの削除

アプリ内でイベントを削除すると、そのイベントの情報と、アプリ専用領域にコピーした背景写真が削除されます。 本アプリをアンインストールすると、端末内に保存されたすべてのデータが削除されます。 当事業者はデータを預かっていないため、当事業者側で削除が必要なデータはありません。

9情報の安全管理

本アプリの機能は端末内で完結し、当事業者がユーザーのデータを預かることはありません。 端末内に保存されたデータの保護は、Android OS のアプリサンドボックスおよび 端末のロック機能等に依存します。端末の紛失・盗難に備え、画面ロックの設定をおすすめします。

10お子様の利用について

本アプリは、13歳未満のお子様を主たる対象とするアプリとして設計・配信していません。 当事業者は、お子様から意図的に個人情報を収集することはありません。
