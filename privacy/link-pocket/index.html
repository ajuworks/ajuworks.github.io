プライバシーポリシー

リンクポケット（com.ajuworks.linkpocket）／ Aju Works

最終更新: 2026年10月7日 事業者: Aju Works（個人事業）

1はじめに

本プライバシーポリシー（以下「本ポリシー」）は、Aju Works（以下「当事業者」）が提供するAndroidアプリ「リンクポケット」（英語表記: Link Pocket、パッケージ名: com.ajuworks.linkpocket、以下「本アプリ」）における情報の取り扱いについて定めるものです。

本アプリは、Chrome などのブラウザや他のアプリの共有メニューから受け取ったリンク（URL）を、あとで見るために端末内に保存・整理するアプリです。本ポリシーに定めのない事項については、Aju Works 共通プライバシーポリシー が適用されます。

2アカウント登録について

本アプリの利用にあたって、アカウント登録・ログインは必要ありません。当事業者は、本アプリを通じて氏名・メールアドレス・電話番号・住所を取得しません。

ただし、ユーザーご自身がお問い合わせのために送信された情報（メール本文に記載された氏名・連絡先等）は、お問い合わせへの回答のために利用します。

3端末内に保存する情報

本アプリは、ユーザーが保存したリンクについて次の情報を、端末内のデータベース（SQLite）にのみ保存します。

  • URL（https:// で始まるもの）と、そのドメイン名
  • タイトル（共有元のアプリから渡された件名、またはユーザーが入力・編集したもの）
  • ユーザーが入力したメモ・タグ、お気に入り・秘密タグの設定
  • 保存日時・更新日時・最後に開いた日時

あわせて、アプリの設定（ロックのON/OFF、PINコード、リンクの開き方、Cookie・キャッシュ削除の設定、スクリーンショット禁止の設定、タグの候補など）を端末内のアプリ専用領域に保存します。

これらの情報を当事業者のサーバーやクラウドへ送信・同期することはありません。本アプリは Android のバックアップ機能（クラウドバックアップ・機種変更時のデータ転送）の対象外としているため、これらの情報が Google ドライブ等へ自動でバックアップされることもありません。

4共有メニューからの受け取り

他のアプリで「共有」を選び本アプリを選択した場合、共有されたテキストから最初の https:// のURLと、共有元のアプリが渡した件名（ページタイトル等）を受け取り、端末内に保存します。URLが含まれない場合は何も保存しません。ユーザーが共有操作をしていないときに、他のアプリの情報や閲覧履歴を読み取ることはありません。

5リンクを開くとき（Webページの表示）

保存したリンクは、次のいずれかの方法で開くことができます（設定または詳細画面で選択）。

  • Chrome風で開く: Android の Custom Tabs を利用し、端末のブラウザアプリ（Chrome 等）でページを表示します。この場合、閲覧履歴・Cookie 等の扱いはそのブラウザアプリの設定とプライバシーポリシーに従います。
  • プライベート表示で開く: 本アプリ内の表示画面（Android System WebView）でページを表示します。本アプリはこの画面での閲覧履歴を保存せず、初期設定では画面を閉じるときに Cookie とキャッシュを削除します（設定で変更できます）。

いずれの方法でも、ページの表示のためにユーザーの端末からアクセス先の Web サイトへ直接通信が行われます。アクセス先の Web サイトが Cookie やアクセス解析などを通じて取得する情報は、当事業者ではなく各 Web サイトのプライバシーポリシーに従って取り扱われます。当事業者がこの通信の内容を受け取ることはありません。

6生体認証・PINロック（任意）

設定でロックを有効にした場合、アプリの起動時や秘密タグを付けたリンクを開くときに、指紋・顔などの生体認証または PIN コードによる解除を求めます。生体認証は Android の生体認証機能（BiometricPrompt）を利用しており、本アプリが受け取るのは認証の成否だけです。指紋・顔などの生体情報を本アプリや当事業者が取得・保存することはありません。

PIN コードは端末内のアプリ専用領域にのみ保存し、外部へ送信しません。

7コピー・共有・エクスポート

ユーザーが「URLをコピー」「共有」「データをエクスポート」を選んだ場合にのみ、URL または保存データ（JSON形式）を Android のクリップボード、またはユーザーが選んだ共有先アプリへ渡します。クリップボードの内容は Android の仕組みにより他のアプリから参照される場合があります。共有先・貼り付け先での取り扱いは、それぞれのアプリのプライバシーポリシーに従います。当事業者が保存データを自動的に外部へ送信することはありません。

8広告・アクセス解析・外部サービス

本アプリは、広告配信SDK、アクセス解析ツール、クラッシュレポートの送信、トラッキングを使用していません。広告ID（Advertising ID）も使用しません。

本アプリが利用する外部ライブラリは、Android 標準の AndroidX・Material Components（画面表示、Custom Tabs、生体認証）のみで、これらを通じて当事業者や第三者へ利用データを送信することはありません。

9権限

  • インターネット（INTERNET）— 保存したリンクのページを表示するため
  • 生体認証（USE_BIOMETRIC。古い Android 向けの USE_FINGERPRINT を含む）— 任意のロック機能のため

連絡先・位置情報・カメラ・マイク・写真・ストレージ全体へのアクセス権限は使用しません。

10データの削除

保存したリンクは、詳細画面から1件ずつ削除できます。設定の「全データ削除」を選ぶと、保存したすべてのリンクと設定を削除し、あわせてプライベート表示の Cookie・Web ストレージとクリップボードの内容を消去します。アプリをアンインストールした場合も、端末内に保存された本アプリのデータは削除されます。当事業者はこれらのデータを保持していないため、当事業者側で削除する対象はありません。

11情報の安全管理

本アプリのデータは端末内で完結し、当事業者が預かることがないため、当事業者側での漏えいリスクを構造的に低減しています。端末内に保存されたデータの保護は、Android OS のアプリサンドボックスおよび端末のロック機能等に依存します。端末の紛失・盗難に備え、端末の画面ロックの設定をおすすめします。

12お子様の利用について

本アプリは、13歳未満のお子様を対象とするアプリとして設計・配信していません。当事業者は、お子様から意図的に個人情報を収集することはありません。
