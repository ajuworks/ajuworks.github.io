プライバシーポリシー

電池と電球口金の見分け帳（com.ajuworks.kikakumiwake）／ Aju Works

最終更新: 2026年11月13日 事業者: Aju Works（個人事業）

1はじめに

本ポリシーは、Aju Works（以下「当方」）が提供する Android アプリ「電池と電球口金の見分け帳」（パッケージ名: com.ajuworks.kikakumiwake、以下「本アプリ」）で扱う情報の取り扱いを定めるものです。

本アプリは、電池（単1〜単5・9V 形・ボタン電池）の型番の読み方と寸法、電球の口金（E26・E17・E11・E12・E10・E14・E39）の大きさと見分け方を表示する辞典です。アプリの中に内容を持っていて、アプリ自身が内容を取りに行く通信はしません。

本ポリシーに定めのない事項については、Aju Works 共通プライバシーポリシー が適用されます。

2見た項目・検索語の扱い（保存しません）

どの項目を見たか、何を検索したか（名前や測った直径の数字）は、この端末の中で画面を表示するためだけに使います。端末には保存せず（お気に入り・メモ・履歴・設定の保存機能はありません）、当方のサーバーへも送りません。当方は自前のサーバーを持たず、アカウント登録も不要です。アプリを閉じると、これらの内容は残りません。

3バックアップと機種変更

本アプリが端末に保存するユーザーの情報はありません。Google のバックアップと機種変更の転送の対象からも、本アプリのデータを除外しています。

4外部リンク

出典の URL は画面に文字で表示するだけで、アプリからブラウザなどで開くことはありません。本アプリがクリップボードを読むことはありません。

5広告（Google AdMob）

  • ホーム画面、項目の一覧の画面、「すべてと検索」の画面の最下部に、Google AdMob の広告を表示します。項目の詳細・出典と使いかたの画面には表示しません。
  • 広告の配信のため、Google AdMob（広告 SDK）が通信します。広告 ID、IP アドレス（おおよその位置を推定することがあります）、アプリの操作、アプリの起動時間や動作の状況などの診断情報を扱います。これらの情報は Google に送られます（Google がこれらを収集し、広告の配信などに使います）。
  • これらは、広告の配信・分析・不正防止の 3 つの目的で使われます。
  • 広告 ID は、Android の設定でリセットまたは削除できます。
  • どの項目を見たか、何を検索したかを、広告のために送ることはありません。
  • 地域によっては、広告に関する同意の確認画面（Google の User Messaging Platform）を表示します。同意の状態は、この広告 SDK が端末に保存します。同意の内容は、アプリ内の案内の画面（対象の地域のみ）から見直せます。
  • Google による情報の取扱いは Google プライバシー ポリシー をご確認ください。

同意の確認画面は、ホーム画面にいるときだけ表示します。本アプリに有料の機能はありません。

6出典と内容の位置づけ

出典は、アプリの「出典と使いかた」の画面に一覧で示しています。出典は、中身を自分の言葉でまとめるときに読んだ案内で、確認日は、アプリの作成時に読んだ日です。電球の口金の値は、記事や解説などの二次資料にもとづく目安で、規格票とは照合していません。

このアプリは、出典に挙げたメーカー・団体・官公庁が作成したものではなく、これらとは関係がありません。この辞典の互換は目安で、機器の指定品番が優先です。

ボタン電池の画面に、国民生活センター（2024年7月31日公表）を出典とする注意（子どもの手の届かないところに置き、誤飲が疑われる場合は速やかに医療機関を受診する）を表示します。本アプリは医療の助言をしません。

7権限

本アプリが自前で宣言する権限はありません。広告 SDK が、通信（INTERNET）、ネットワークの状態の確認（ACCESS_NETWORK_STATE）、広告 ID（AD_ID）の権限を加えます。アプリ内部の受信用に、自アプリ専用の権限（DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION。他のアプリは使えません）が加わります。

Topics や属性の計測などの広告サービスの権限（ACCESS_ADSERVICES_*）は、本アプリでは外しています。カメラ・位置情報・連絡先・ストレージ・通知などの権限は宣言していません。平文（http）の通信は許可していません。

8データの削除

本アプリは端末にユーザーの情報を保存せず、当方もこれらのデータを保持していないため、当方側で削除する対象はありません。広告 ID は、Android の設定でリセットまたは削除できます。

9対象年齢・配信地域

このアプリは 18 歳以上の方を対象としています。子ども向けには設計・配信していません。当方は、お子様から意図的に個人情報を収集することはありません。配信は日本のみです。
