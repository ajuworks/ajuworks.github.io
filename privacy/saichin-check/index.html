最低賃金 時給・月給の参考比較（com.ajuworks.saichincheck）／ Aju Works

最終更新: 2026年11月13日 事業者: Aju Works（個人事業）

1はじめに

本ポリシーは、Aju Works（以下「当方」）が提供する Android アプリ「最低賃金 時給・月給の参考比較」（アプリ名: 最低賃金 時給・月給の参考比較、パッケージ名: com.ajuworks.saichincheck、以下「本アプリ」）で扱う情報の取り扱いを定めるものです。

端末に表示される名前は『時給・月給の最低賃金 参考比較』です。

本アプリは、時給・月給から出した時間額と、地域別の最低賃金の額を数値で並べる参考比較のアプリです。賃金が正しいか（法令に合うか）は判断しません。

本ポリシーに定めのない事項については、Aju Works 共通プライバシーポリシー が適用されます。

2入力した内容の扱い

  • 選んだ都道府県、賃金の対象期間（開始日・終了日）、途中で最低賃金が変わったかの確認の回答、時給・月給、比較に含めない賃金、その他の手当、所定労働時間、利用者が入れた最低賃金の額は、アプリのメモリ上だけに置き、アプリが終了すると消えます（画面の回転や戻る操作では残ります）。
  • 自由記述の欄はありません。氏名・勤務先・住所・給与明細の入力欄はありません。

入力した金額・時間は、当方のサーバーを含め外部へ送りません。当方はサーバーを持たず、アカウント登録も不要です。

3保存・履歴

本アプリは、入力内容を端末に保存しません。履歴の機能もありません。

4バックアップと機種変更

本アプリは入力内容を保存しないため、Google のバックアップと機種変更の転送の対象にするデータはありません（設定も含め、両方から除外しています）。

5コピーと共有

  • 「コピー」を押したときだけ、参考比較の文面を端末のクリップボードに書き込みます。コピーした文面は、ほかの文字をコピーするまでクリップボードに残ります。本アプリがクリップボードを読むことはありません。
  • 「共有」を押したときだけ、文面を端末の共有画面に渡します。共有した先の文面は、本アプリでは消せません。
  • 文面に、入力した時給・月給・所定労働時間・手当の額・計算した時間額・差は含みません。選んだ都道府県の名前、本アプリに収録した決定額と発効日、注意書き、出典だけを含みます。

6広告（Google AdMob）

  • 結果画面の下部に、Google AdMob の広告を表示します。入力などほかの画面には表示しません。
  • 広告の配信のため、Google AdMob（広告 SDK）が通信します。広告 ID、IP アドレス（おおよその位置を推定することがあります）、アプリの操作、診断情報（不具合の記録など）などを扱います。
  • これらは、広告の配信・分析・不正防止の 3 つの目的で使われます。
  • 広告 ID は、端末の設定でリセットまたは削除できます。
  • 入力した内容（氏名・メモ・金額・検索語など）を、広告のために送ることはありません。
  • 地域によっては、広告に関する同意の確認画面（Google の User Messaging Platform）を表示します。同意の内容は、アプリ内の案内の画面から見直せます。
  • Google による情報の取扱いは Google プライバシー ポリシー をご確認ください。

本アプリに有料の機能（Pro）はありません。

7出典と位置づけ

出典：厚生労働省ホームページ「令和8年度 地域別最低賃金 全国一覧」（https://www.mhlw.go.jp/content/11200000/001753404.pdf）（2026年11月11日取得）

出典：各都道府県労働局ホームページの最低賃金改正の発表（2026年11月11日確認）

このアプリの表示は、上の資料と都道府県労働局の発表をもとに当方が編集・加工して作成したものです。本アプリは当方が作成したもので、国・厚生労働省・労働局が作成したものではなく、関係もありません。

出典の確認から 6 か月を過ぎたとき、本アプリは端末の日付をもとに注意を表示します。この表示に通信は使いません。

8権限

本アプリが自前で宣言する権限はありません。広告 SDK（Google Mobile Ads・User Messaging Platform）が、通信（INTERNET）、ネットワークの状態の確認（ACCESS_NETWORK_STATE）、広告 ID（AD_ID）などの権限を加えます。広告に関する権限（ACCESS_ADSERVICES_AD_ID・ACCESS_ADSERVICES_ATTRIBUTION・ACCESS_ADSERVICES_TOPICS）も広告 SDK により加わります。連絡先、位置情報、カメラ、ストレージ、通知、電話の権限は使いません。

9データの削除

本アプリは入力内容を保存しないため、削除の操作は不要です。アプリが終了すると入力内容は消えます。

10お子様の利用について

このアプリは 18 歳以上の方を対象としています。子ども向けには設計・配信していません。当方は、お子様から意図的に個人情報を収集することはありません。
