ヘボン式ローマ字 氏名の変換（com.ajuworks.hebonromaji）／ Aju Works

最終更新: 2026年11月13日 事業者: Aju Works（個人事業）

1はじめに

本ポリシーは、Aju Works（以下「当方」）が提供する Android アプリ「ヘボン式ローマ字 氏名の変換」（アプリ名: ヘボン式ローマ字、パッケージ名: com.ajuworks.hebonromaji、以下「本アプリ」）で扱う情報の取り扱いを定めるものです。

端末に表示される名前は『ヘボン式ローマ字』です。

本アプリは、戸籍のフリガナ（かな）の氏名を入れると、ヘボン式ローマ字の綴りの一例を表示し、入力した綴りとの一致・相違を示すアプリです。旅券の記載を保証するものではありません。

本ポリシーに定めのない事項については、Aju Works 共通プライバシーポリシー が適用されます。

2入力した内容の扱い

  • 入力した氏名（かな）、のばす音・区切る音の選択、照合のために入れた英字の綴りは、初期設定では、アプリのメモリ上だけに置き、アプリが終了すると消えます（画面の回転や戻る操作では残ります）。
  • 入力できるのは、氏名（かな）、照合のための英字の綴り（数字は入力できません）、家族メモのニックネーム（10 文字まで。数字・改行・絵文字は入力できません）だけです。住所・生年月日・性別・本籍・マイナンバーなどの入力欄はありません。
  • カード番号・旅券番号は入力しないでください。

入力した氏名と綴りは外部へ送りません。当方はサーバーを持たず、アカウント登録も不要です。

3家族メモ（端末内に保存。初期設定はオフ）

設定で「家族メモを保存する」をオンにしたときだけ、利用者が「家族メモに保存」を押した 1 件ごとに、次の内容を保存します。自動では保存しません。

  • ニックネーム（任意）、かな、のばす音・区切る音の選択
  • 変換した綴り（注意印のない部分だけ）、照合のために入れた綴り（入力があったときだけ）
  • 規則の版、保存日時

保存先は、この端末のアプリ専用の領域（noBackupFilesDir の 1 ファイル）だけです。外部ストレージや共有領域には書きません。保存は 20 件までです。

削除は、1 件ずつの削除、設定からの全件削除、またはアプリのアンインストールでできます。保存をオフに戻すときは、保存した分を削除するか残すかを選べます。残した分も、設定から全件削除できます。

削除や保存の切り替えが端末の都合で完了できなかったときは、画面でお知らせします。元の状態のまま止まった場合は、元の内容が残ります。削除そのものは完了し、端末内の一時ファイルの一部だけが消せなかった場合は、家族メモは削除済みであること（削除後の件数）と、残ったファイルはアンインストールですべて消えることを、画面でお知らせします。

保存の形式は将来の更新でも読めるようにしています。読めないファイルは「.corrupt-番号」の名前で残し、空の状態から始めて、画面でお知らせします。

4バックアップと機種変更

家族メモと設定は、Google のバックアップに含まれず、機種変更で新しい端末へ移りません。バックアップと機種変更の転送の両方から除外しています。

5コピー・共有

  • 「コピー」を押したときだけ、綴りを端末のクリップボードに書き込みます。端末の機能で、内容を表示しない扱いにします。コピーした綴りは、ほかの文字をコピーするまでクリップボードに残ります。本アプリがクリップボードを読むことはありません。
  • 共有・印刷・ファイルへの書き出しの機能はありません。

6広告（Google AdMob）

  • 結果画面の下部に、Google AdMob の広告を表示します。入力などほかの画面には表示しません。
  • 広告の配信のため、Google AdMob（広告 SDK）が通信します。広告 ID、IP アドレス（おおよその位置を推定することがあります）、アプリの操作、診断情報（不具合の記録など）などを扱います。
  • これらは、広告の配信・分析・不正防止の 3 つの目的で使われます。
  • 広告 ID は、端末の設定でリセットまたは削除できます。
  • 入力した内容（氏名・メモ・金額・検索語など）を、広告のために送ることはありません。
  • 地域によっては、広告に関する同意の確認画面（Google の User Messaging Platform）を表示します。同意の内容は、アプリ内の案内の画面から見直せます。
  • Google による情報の取扱いは Google プライバシー ポリシー をご確認ください。

本アプリに有料の機能（Pro）はなく、生成 AI の機能もありません。

7外部のブラウザで開く案内

出典や案内の画面にある「外部のブラウザで開きます」と表示された項目を押したときだけ、外部のブラウザで開きます。本アプリは、ブラウザの画面を組み込んで表示することはありません。

8出典と位置づけ

出典：外務省ウェブサイト「ヘボン式ローマ字綴方表」（https://www.ezairyu.mofa.go.jp/passport/hebon.html）（2026年11月11日に利用）をもとに、当方が編集・加工して作成しています。

本アプリは当方が作成したもので、外務省その他の国・行政機関とは関係がなく、国・行政機関が作成・提供したものではありません。このアプリは政府機関を代表するものではありません。

出典を確かめた日から 18 か月を過ぎたとき、本アプリは端末の日付をもとに注意を表示します。この表示に通信は使いません。

9権限

本アプリが自前で宣言する権限はありません。広告 SDK（Google Mobile Ads・User Messaging Platform）が、通信（INTERNET）、ネットワークの状態の確認（ACCESS_NETWORK_STATE）、広告 ID（AD_ID）などの権限を加えます。広告に関する権限（ACCESS_ADSERVICES_AD_ID・ACCESS_ADSERVICES_ATTRIBUTION・ACCESS_ADSERVICES_TOPICS）も広告 SDK により加わります。連絡先、位置情報、カメラ、ストレージ、通知、電話の権限は使いません。

平文（http）の通信は許可していません。

10データの削除

家族メモと設定は、1 件ずつの削除、設定からの全件削除、またはアプリのアンインストールで消えます。コピーしたクリップボードの内容は、ほかの文字をコピーすると置き換わります。

当方はこれらのデータを保持していないため、当方側で削除する対象はありません。

11お子様の利用について

このアプリは 18 歳以上の方を対象としています。子ども向けには設計・配信していません。当方は、お子様から意図的に個人情報を収集することはありません。
