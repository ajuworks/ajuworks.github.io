車の警告灯 いまどうする？ - 色と形で意味と目安（com.ajuworks.kurumakeikoku）／ Aju Works

最終更新: 2026年11月13日 事業者: Aju Works（個人事業）

このアプリの情報の取り扱い

本アプリは、メーターに点いた警告灯の色と形から、一般的な意味と対処の目安の例を調べる辞典です。警告灯の中身はアプリの中に入っていて、アプリ自身が中身を取りに行く通信はしません。

当事業者が集める情報

本アプリ自身は、氏名・連絡先・位置情報・写真などの個人情報を集めず、当事業者のサーバーへ送信もしません（当事業者はこのアプリのためのサーバーを持ちません）。どの灯を見たか、どの色を選んだかは、画面を切り替えるためだけに端末の中で使い、保存せず、送信しません。アカウント登録は不要です。アプリのデータは Android のバックアップと機種変更のデータ移行の対象にしていません。

広告配信（Google AdMob）

ホーム画面の最下部に、Google LLC の広告サービス（AdMob）によるバナー広告を表示します。広告の配信のため、AdMob（Google Mobile Ads SDK）が自動的に通信し、次の情報を収集し、Google と共有することがあります。目的は、広告の配信、分析、不正の防止です。通信は暗号化（TLS）されます。

  • IP アドレス（おおよその位置の推定に使われることがあります）
  • アプリの操作に関する情報（起動・タップなど）
  • 診断情報（アプリの起動時間・動作の遅延・電力の使用など）
  • 広告 ID・アプリセット ID などの端末の識別子

これらの情報の扱いは、Google の規約に従います。詳しくは Google のパートナー サイトやアプリでのデータ使用 と Google プライバシー ポリシー をご覧ください。このアプリの中での操作の内容（どの灯を見たかなど）は、広告には渡しません。

広告 ID について

本アプリは Android の広告 ID を、広告の配信・分析・不正の防止のために使います。広告 ID は、端末の設定（Google の「広告」の設定）で、リセットしたり、広告のパーソナライズをオプトアウト（無効化）したりできます。

広告に関する同意

本アプリは日本でのみ配信しています。法令や Google の方針により同意が必要な場合には、広告に関する同意の確認画面（Google の User Messaging Platform）が表示されることがあります。表示する場合は、ホーム画面にいるときだけ表示します。同意の内容は、アプリの「出典と使いかた」から見直せる場合があります。同意しない場合、広告の配信に必要な情報の収集・利用が制限されることがあります。

権限

本アプリ自身が宣言する権限はありません。広告の SDK が、通信（INTERNET）、ネットワークの状態の確認（ACCESS_NETWORK_STATE）、広告 ID の利用（AD_ID）の権限を加えます。カメラ・位置情報・連絡先・通知などの権限は使いません。

出典の URL

出典の URL は画面に文字で表示するだけで、アプリから開くことはありません。長押しでクリップボードにコピーできます。

配信地域・対象年齢

本アプリの配信は日本のみです。一般向け（13 歳以上）で、子ども向けのアプリではありません。13 歳未満の方から、意図して個人情報を集めることはありません。

目安と提供元について

本アプリが示す目安は、取扱説明書の記述をもとにした一般的な例で、お車の取扱説明書の記載が正です。本アプリは、自動車メーカー・国・JAF が作成したものではなく、それらとは関係がありません。

今後の変更

本ポリシーは、アプリの機能の変更（たとえば有料機能の追加）や法令の変更に応じて改定することがあります。改定したときは、このページに最終更新日とともに掲載します。

共通ポリシーとの関係

広告・課金・外部プラットフォーム・子どものプライバシーなどの共通事項は 共通プライバシーポリシー に記載しています。 本ページと共通ポリシーは併せて適用され、内容が異なる場合は本ページを優先します。 すべてのアプリの一覧は アプリ別プライバシーポリシー をご覧ください。
