プライバシーポリシー

しみ抜き・汚れ いまどうする？（com.ajuworks.yogorehayami）／ Aju Works

最終更新: 2026年11月13日 事業者: Aju Works（個人事業）

1はじめに

本ポリシーは、Aju Works（以下「当方」）が提供する Android アプリ「しみ抜き・汚れ いまどうする？」（パッケージ名: com.ajuworks.yogorehayami、以下「本アプリ」）で扱う情報の取り扱いを定めるものです。

端末に表示される名前は『汚れ・しみ いまどうする？』です。

本アプリは、衣類のしみ・住まいの汚れを種類から引く応急の手順の辞典と、洗剤の組み合わせの表（混ぜるな危険）を表示するアプリです。アプリの中に内容を持っていて、アプリ自身が内容を取りに行く通信はしません。

本ポリシーに定めのない事項については、Aju Works 共通プライバシーポリシー が適用されます。

2見た項目・検索・選んだ内容の扱い

どの汚れを見たか、何を検索したか、どの洗剤の種類を選んだかは、この端末の中で画面を表示するためだけに使います。保存せず、当方のサーバーへも送りません。当方はサーバーを持たず、アカウント登録も不要です。

3お気に入りとメモ（端末内に保存）

お気に入りとメモは、この端末の中だけに保存し、アプリは送信しません。保存先は、アプリ専用の領域（noBackupFilesDir）の 1 つのファイルだけです。外部ストレージや共有領域には書きません。

1 件ずつ削除、またはすべて削除できます。保存データを読み込めないときは、元のファイルを変えず、保存と削除を止めて、読み直せます。壊れたファイルは別名（.corrupt-番号）で残し、空の状態から始めます。端末の都合で一部のファイルを消せなかったときは、画面でお知らせします。

メモには、氏名・住所・電話番号などの個人情報を書かないでください。

メモを表示している間は、最近使った画面の一覧に画面の画像を残さないようにしています（Android のバージョンにより方法が異なります）。

4バックアップと機種変更

お気に入りとメモ、設定は、Google のバックアップに含まれず、機種変更で新しい端末へ移りません。バックアップと機種変更の転送の両方から除外しています。アンインストールで消えます。

5外部リンクとコピー

  • 出典の URL は画面に文字で表示するだけで、アプリからブラウザなどで開くことはありません。
  • 長押しでクリップボードにコピーできます。コピーした文字は、ほかの文字をコピーするまで端末に残ります。本アプリがクリップボードを読むことはありません。

6広告（Google AdMob）

  • ホーム画面、項目の一覧の画面、「すべての項目と検索」の画面の最下部に、Google AdMob の広告を表示します。結果（詳細）・混ぜるな危険・お気に入りとメモ・出典と使いかたの画面には表示しません。
  • 広告の配信のため、Google AdMob（広告 SDK）が通信します。広告 ID、IP アドレス（おおよその位置を推定することがあります）、アプリの操作、診断情報（不具合の記録など）などを扱います。
  • これらは、広告の配信・分析・不正防止の 3 つの目的で使われます。
  • 広告 ID は、端末の設定でリセットまたは削除できます。
  • 入力した内容（氏名・メモ・金額・検索語など）を、広告のために送ることはありません。
  • 地域によっては、広告に関する同意の確認画面（Google の User Messaging Platform）を表示します。同意の内容は、アプリ内の案内の画面から見直せます。
  • Google による情報の取扱いは Google プライバシー ポリシー をご確認ください。

同意の確認画面は、ホーム画面にいるときだけ表示します。本アプリに有料の機能（Pro）はありません。

7出典と内容の位置づけ

出典は、アプリの「出典と使いかた」の画面に一覧で示しています。出典は、中身を自分の言葉でまとめるときに読んだ案内です。確認日は、アプリの作成時に読んだ日です。

このアプリは、出典に挙げたメーカー・団体・官公庁が作成したものではなく、これらとは関係がありません。

この辞典は、出典をもとに自分の言葉でまとめた一般的な目安です。落ちることや、安全を保証するものではありません。衣類の洗濯表示・製品の表示・取扱説明書が優先です。このアプリは医療の助言をしません。

確認日から 18 か月を過ぎたとき、本アプリは端末の日付をもとに注意を表示します。この表示に通信は使いません。

8権限

本アプリが自前で宣言する権限はありません。広告 SDK が、通信（INTERNET）、ネットワークの状態の確認（ACCESS_NETWORK_STATE）、広告 ID（AD_ID）の権限を加えます。アプリ内部の受信用に、自アプリ専用の権限（DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION。他のアプリは使えません）が加わります。

Topics や属性の計測、広告 ID の読み取りに関する広告サービスの権限（ACCESS_ADSERVICES_*）は、本アプリでは外しています。カメラ・位置情報・連絡先・通知などの権限は宣言していません。平文（http）の通信は許可していません。

9データの削除

お気に入りとメモは、アプリ内で 1 件ずつ、またはすべて削除できます。アプリを削除しても消えます。

当方はこれらのデータを保持していないため、当方側で削除する対象はありません。

10対象年齢

このアプリは 18 歳以上の方を対象としています。子ども向けには設計・配信していません。当方は、お子様から意図的に個人情報を収集することはありません。
