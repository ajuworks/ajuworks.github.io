拡張子の見分け帳（com.ajuworks.kakuchoshi）／ Aju Works

最終更新: 2026年11月14日 事業者: Aju Works（個人事業）

1はじめに

本ポリシーは、Aju Works（以下「当方」）が提供する Android アプリ「拡張子の見分け帳」（パッケージ名: com.ajuworks.kakuchoshi、以下「本アプリ」）で扱う情報の取り扱いを定めるものです。

本アプリは、「.pdf」「.zip」などの拡張子について、何のファイルか・主に開くアプリの種類・似た拡張子との違いを表示する辞典です。収録は 180 件（14 分野）の抜粋です。アプリの中に内容を持っていて、アプリ自身が内容を取りに行く通信はしません。ファイルの安全性は判断しません。

本ポリシーに定めのない事項については、Aju Works 共通プライバシーポリシー が適用されます。

2端末のファイルを読みません

本アプリは、端末の中のファイルを読みません。端末の中のファイルを探したり、開いたり、選んだりもせず、他のアプリからファイルを受け取る機能もありません。ストレージ・写真・動画・音声・ファイルに関する権限は宣言していません。

入力欄に入れる「名前.pdf.exe」のようなファイル名は、利用者がご自身で入力した文字列だけを、端末の中で辞典の拡張子から探すために使います。ファイルそのものの中身や、端末にあるファイルの有無は扱いません。

3見た項目・入力した語の扱い（保存しません）

どの拡張子を見たか、何を入力したか（拡張子・ファイル名・日本語の語など）は、この端末の中で画面を表示するためだけに使います。端末には保存せず（お気に入り・メモ・履歴・設定の保存機能はありません）、当方のサーバーへも送りません。当方は自前のサーバーを持たず、アカウント登録も不要です。アプリを閉じると、これらの内容は残りません。

4バックアップと機種変更

本アプリが端末に保存するユーザーの情報はありません。Google のバックアップと機種変更の転送の対象からも、本アプリのデータを除外しています。

5クリップボードと外部リンク

出典の URL を長押ししたときだけ、その URL をクリップボードに書き込みます。本アプリがクリップボードの中身を読み取ることはありません。

出典の URL は画面に文字で表示するだけで、アプリからブラウザなどで開くことはありません。

6広告（Google AdMob）

  • 分野ごとの一覧の画面の最下部に、Google AdMob の広告を表示します。ホーム画面・項目の詳細・出典の画面には表示しません。全画面の広告は出しません。
  • 広告の配信のため、Google AdMob（広告 SDK）が通信します。広告 ID、IP アドレス（おおよその位置を推定することがあります）、アプリの操作、アプリの起動時間や動作の状況などの診断情報を扱います。これらの情報は Google に送られます（Google がこれらを収集し、広告の配信などに使います）。
  • これらは、広告の配信・分析・不正防止の 3 つの目的で使われます。
  • 広告 ID は、Android の設定でリセットまたは削除できます。
  • どの拡張子を見たか、何を入力したか、入力したファイル名を、広告のために送ることはありません。
  • 地域によっては、広告に関する同意の確認画面（Google の User Messaging Platform）を表示します。同意の状態は、この広告 SDK が端末に保存します。同意の内容は、アプリ内の案内の画面（対象の地域のみ）から見直せます。
  • Google による情報の取扱いは Google プライバシー ポリシー をご確認ください。

同意の確認画面は、ホーム画面にいるときだけ表示します。本アプリに有料の機能はありません。

7出典と内容の位置づけ

出典は、アプリの「出典・このアプリについて」の画面に一覧で示しています（資料名・発行者・版または年・取得日・URL）。拡張子の説明・開くアプリの種類・違いは、当方が自分の言葉で書いたもので、他の辞典・Web・アプリ・書籍の説明文や表は写していません。出典には、規格団体や開発元など、さまざまな発行者の資料が並びます。確認日は、アプリの作成時に資料を参照した日です。

製品名は各社の商標です。本アプリは各社と関係がなく、特定の製品を推奨するものではありません。出典に挙げた機関・企業が作成したものではなく、これらとは関係がありません。

拡張子はファイルの種類の目安で、名前と中身が一致するとは限りません。本アプリは、ファイルの安全性を判断できません。ファイルの中身の判定、変換、ファイルの開き方や実行・導入の手順は扱いません。

8権限

本アプリが自前で宣言する権限はありません。広告 SDK が、通信（INTERNET）、ネットワークの状態の確認（ACCESS_NETWORK_STATE）、広告 ID（AD_ID）の権限を加えます。アプリ内部の受信用に、自アプリ専用の権限（DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION。他のアプリは使えません）が加わります。

Topics や属性の計測などの広告サービスの権限（ACCESS_ADSERVICES_*）は、本アプリでは外しています。ストレージ・メディア・ファイル・カメラ・位置情報・連絡先・通知などの権限は宣言していません。平文（http）の通信は許可していません。

9データの削除

本アプリは端末にユーザーの情報を保存せず、当方もこれらのデータを保持していないため、当方側で削除する対象はありません。広告 ID は、Android の設定でリセットまたは削除できます。

10対象年齢・配信地域

このアプリは 18 歳以上の方を対象としています。子ども向けには設計・配信していません。当方は、お子様から意図的に個人情報を収集することはありません。配信は日本のみです。
